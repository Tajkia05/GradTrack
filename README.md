# GradTrack

GradTrack is a web-based system for managing graduate degree progress, academic milestones, committee-related processes, and administrative approval workflows. The prototype targets a Computer Science PhD program, using UAlbany's actual milestone and deadline rules as the reference model.

## Tech Stack

- **Frontend**: React
- **Backend**: Python + FastAPI
- **Database**: PostgreSQL
- **Auth**: JWT-based authentication
- **Testing**: pytest (backend), Jest / React Testing Library (frontend)
- **CI**: GitHub Actions
